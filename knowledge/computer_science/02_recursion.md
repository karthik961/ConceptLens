# Recursion and base cases

**Concept notes written for the ConceptLens starter demo.**

A recursive function calls itself directly or indirectly while solving a smaller instance of a problem. A terminating recursive algorithm needs a base case and a progression that eventually reaches the base case.

Without effective progress toward a stopping condition, repeated recursive calls can continue until the call stack is exhausted. The base case is not merely an optimization; it defines when recursion stops and what result is returned.

Iteration and recursion can express similar computations. Which is appropriate depends on problem structure, language runtime, readability and resource constraints.
