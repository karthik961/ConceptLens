# Series and parallel circuits

**Concept notes written for the ConceptLens starter demo.**

In a single-loop series circuit, all components lie on one path. The same current flows through each component in that loop under steady-state conditions. If one component breaks the loop, current stops throughout the loop.

In parallel circuits, branches provide separate conductive paths between common connection points. Opening one branch can stop current there while other complete branches continue to carry current. The same voltage appears across ideal parallel branches sharing the same pair of nodes.

Do not conclude that every bulb must go out when any bulb fails: the effect depends on whether the circuit is series or parallel, and where the break occurs. Understanding which paths remain closed is more reliable than memorizing a slogan.
